## 🚀 How to Use

1. Start a new lab on INE Security.
2. Copy `template.md` into the relevant category folder as `Lab_Name.md`.
3. Take notes, paste commands, and add screenshots as you go.
4. On completion, fill in flags/objectives and key learnings.
5. Update the **Completed Labs** table above with a link to your writeup.
6. Push to GitHub!
